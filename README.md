# ShadowShield

PowerShell-скрипт для быстрой проверки и очистки ПК средствами встроенного **Microsoft Defender**: обновляет сигнатуры, запускает проверку, показывает найденные угрозы и удаляет их только после вашего явного подтверждения — не трогая то, что вы сами разрешили через Defender.

> Скрипт не содержит собственного антивирусного движка — он управляет штатным Defender через официальный PowerShell-модуль `Defender`. Все проверки реально выполняет сам Defender.

---

## Что делает скрипт

1. **Проверка состояния.** Смотрит, включён ли Defender, не работает ли он в пассивном режиме (из-за стороннего антивируса) и включена ли защита от несанкционированного доступа (Tamper Protection).
2. **Исключения.** Показывает, сколько у вас настроено исключений (папки, расширения, процессы) — Defender пропустит их сам, скрипт тут ничего не меняет.
3. **Разрешённые угрозы.** Читает журнал Defender и запоминает ID угроз, которые вы разрешили вручную («Allowed»).
4. **Обновление сигнатур** перед проверкой (можно пропустить).
5. **Проверка**: быстрая, полная, одна папка/файл или автономная (офлайн).
6. **Отчёт.** Показывает список всех найденных активных угроз с путями к файлам, помечая разрешённые отдельно.
7. **Подтверждение.** Перед удалением явно спрашивает согласие (ввод слова «да»). Ничего не удаляется молча.
8. **Удаление.** Если среди найденного есть хоть одна разрешённая вами угроза — автоудаление отменяется целиком (так устроен Defender: `Remove-MpThreat` убирает все активные угрозы разом, выбрать отдельные нельзя). В этом случае скрипт просит убрать нужное вручную через журнал защиты.

## Как запустить

PowerShell от имени администратора:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\Defender-QuickClean.ps1
```

### Параметры

| Параметр | Назначение |
|---|---|
| `-ScanType Quick` | Быстрая проверка (по умолчанию) |
| `-ScanType Full` | Полная проверка всего диска, дольше |
| `-ScanType Offline` | Перезагрузка и проверка до загрузки Windows (см. ниже) |
| `-Path "C:\Папка"` | Проверить только указанную папку или файл — быстрее всего |
| `-ReportOnly` | Только показать найденные угрозы, ничего не удалять |
| `-Force` | Не спрашивать подтверждение перед удалением (для автоматизации) |
| `-EnableProtection` | Включить защиту в реальном времени, блокировку PUA и облачную защиту |
| `-SkipUpdate` | Не обновлять сигнатуры перед проверкой |

### Примеры

```powershell
# Проверить только папку загрузок, ничего не удалять
.\Defender-QuickClean.ps1 -Path "$env:USERPROFILE\Downloads" -ReportOnly

# Полная проверка без лишних вопросов (для планировщика задач)
.\Defender-QuickClean.ps1 -ScanType Full -Force

# Автономная проверка (перезагрузка, проверка до старта Windows)
.\Defender-QuickClean.ps1 -ScanType Offline
```

## Подтверждение перед удалением

Скрипт никогда не удаляет файлы молча. Перед удалением он:

1. Печатает список всех найденных активных угроз с путями.
2. Отдельно помечает угрозы, которые вы разрешили — их он не тронет.
3. Спрашивает: *«Введите 'да' для удаления, любой другой ввод отменяет действие»*.

Удаление происходит только после ввода «да». Параметр `-Force` отключает этот вопрос — используйте его только в автоматизации, где подтверждать уже некому.

## Разрешённые угрозы: как это работает

У Defender нет команды «удалить одну угрозу по ID» — `Remove-MpThreat` убирает сразу все активные угрозы. Поэтому если среди найденного есть угроза, которую вы когда-то разрешили («Allowed» в журнале защиты), скрипт **не удаляет ничего вообще**, чтобы случайно не затронуть разрешённое, и просит разобраться вручную:

*Безопасность Windows → Защита от вирусов и угроз → Журнал защиты.*

Там можно удалить конкретные угрозы по одной, оставив разрешённые на месте.

## Почему скрипт не прячет проверку от вируса

Запрятать процесс или замаскировать работающую программу от других программ в системе — это те же приёмы, которыми сами вирусы прячутся от антивирусов. Такой код в скрипт сознательно не добавлен. Вместо этого используются два официальных механизма Defender с тем же результатом:

- **Защита от несанкционированного доступа (Tamper Protection).** Не даёт вредоносной программе (и обычным командам, включая этот скрипт) отключить Defender или изменить его настройки. Через PowerShell её включить нельзя — только вручную:
  *Безопасность Windows → Защита от вирусов и угроз → Параметры защиты от вирусов и угроз → Управление настройками → Защита от несанкционированного доступа.*
  Скрипт проверяет её состояние и предупреждает, если она выключена.

- **Автономная проверка (`-ScanType Offline`).** Компьютер перезагружается в отдельную среду до загрузки Windows. В этот момент ни один вирус из основной системы не запущен — он физически не может ни увидеть проверку, ни помешать ей. Это самый надёжный вариант для упорных заражений, которые не убираются обычной проверкой.

## Ограничения

- Работает только с Microsoft Defender. Если установлен сторонний антивирус, Defender обычно переходит в пассивный режим, и удаление угроз может быть недоступно — скрипт это обнаружит и предупредит.
- Блокировку новых файлов в реальном времени обеспечивает сама защита Defender, а не скрипт — он только следит, чтобы она была включена (`-EnableProtection`).
- Быстрая проверка охватывает самые частые места заражения, а не весь диск. Для полной уверенности используйте `-ScanType Full` или `-ScanType Offline`.
- Скрипт не тестировался на реальном железе с живым заражением — перед важными действиями проверяйте результат вручную через Безопасность Windows.
